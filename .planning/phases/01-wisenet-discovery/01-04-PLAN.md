Decision tree:
```
Field is RED (missing from Wisenet or semantically wrong)
  │
  ├─ Can the field be reconstructed from other Wisenet fields with <10 lines of transparent logic?
  │   (e.g. Current Remaining = Total − sum(session_duration/60 where final_status=ENDED))
  │   └─ YES → derive-client
  │
  ├─ Is losing the field acceptable? (D-05 Should_Credit = canonical example)
  │   └─ YES → accept-loss
  │
  ├─ Does the field need historical / operator-managed state?
  │   (e.g. admin ownership, follow-up notes, manual overrides)
  │   └─ YES → postgres-sidecar
  │
  └─ None of the above → block-cutover (forces Phase 2 gate; requires vendor action or feature rescope)
```
